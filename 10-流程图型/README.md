# 流程图型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以步骤、状态、判断及有向转移构成有向图；数据结构是节点表+边表，边可带条件或触发事件。

## B. 统计图形：统计方式与计算方式

流程图、状态转换图、泳道图、决策树、流程挖掘图；可统计路径频率、步骤耗时、通过率、分支概率和瓶颈，需有过程日志。

## C. 视觉编码：点、线、面、体、符号与色彩

点/形状表示步骤类型；线和箭头表示方向/转移；面/泳道表示角色或阶段；符号遵循开始、处理、判断、结束等约定；色彩突出状态、风险或责任方。

## D. 数据／信息架构

节点字段 node_id、type、label；边字段 source、target、condition、frequency；过程日志含 case_id、activity、timestamp、actor；检查断路、循环和未定义分支。

## E. 视觉叙事架构

从起点沿箭头阅读，在判断节点选择分支，经过处理步骤到达结果；应呈现异常路径、循环和终止条件，而不只是线性步骤。
