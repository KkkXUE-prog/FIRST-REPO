# 比较型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以共同维度和可比对象为基础；核心结构是对象×指标矩阵，确保对象定义、统计口径和单位一致。

## B. 统计图形：统计方式与计算方式

并列/堆叠柱状图、点图、斜率图、哑铃图、雷达图、小多图；计算差值、比率、排名、标准化分数及变化率，比较前需统一分母和基准。

## C. 视觉编码：点、线、面、体、符号与色彩

点表示指标值；线连接对象或表示差值；面表示区间/构成；体积谨慎使用；符号区分对象；色彩区分组别或正负变化，使用一致尺度。

## D. 数据／信息架构

字段包括对象ID、指标、数值、单位、时期、分组、基准及来源；采用长表便于分组；处理单位换算、缺失值、基准差异和样本范围不一致。

## E. 视觉叙事架构

先明确比较问题和基准，再按共同尺度展示差异，突出最大差异/相同点，最后解释差异及数据限制；不能用不一致尺度制造视觉偏差。
