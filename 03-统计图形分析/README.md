本文件夹用于研究和分析统计图形本身，为后续信息图形案例的数据结构识别、统计图形判断与视觉转译提供基础。

## 分析范围

后续逐类研究统计图形时，重点记录：

1. **数据结构**：原始数据表的行列含义、字段类型、维度与度量、分类/数值/时间/空间字段，以及图形所要求的数据粒度。
2. **统计逻辑**：图形回答的问题、数据聚合方式、统计量、计算公式、排序/分组/归一化方法及其前提。
3. **字段映射**：数据字段如何映射到图形变量，例如位置、长度、角度、面积、颜色、形状、连线、分组与层级。
4. **视觉编码**：点、线、面、体、符号、色彩、大小、方向、纹理和空间布局分别表达什么。
5. **阅读与比较**：读者如何读取数值、比较类别、识别趋势/分布/关系/组成/流动，以及图形的感知优势和局限。
6. **适用条件与误读风险**：适合的数据类型、样本规模、尺度要求、数据缺失处理、聚合偏差、视觉误导与可访问性。
7. **信息图形转译**：统计图形如何与说明文字、图标、ISO 图形、插图和视觉叙事结合；区分统计图形原理与信息图形的叙事设计。

## 与其他目录的关系

- 本目录聚焦统计图形的**数据—统计—视觉编码机制**。
- `01-信息图形数据逻辑` 聚焦信息图形类型背后的数据组织逻辑。
- `02-信息图形类型案例` 聚焦用户提供的案例图及其视觉叙事分析。
- 后续案例分析如涉及具体统计图形，应从案例文档链接到本目录对应的统计图形分析文档；本目录也可反向链接相关案例。
