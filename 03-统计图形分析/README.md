# 03-统计图形分析

## 文件夹定位

本文件夹用于研究信息图形案例中**数据结构与统计图形之间的关系**。重点不是给信息图形重新分类，而是理解案例所使用的统计图形如何组织数据、执行计算并形成视觉表达。

## 后续分析范围

后续将结合 RAWGraphs 等可核查的统计可视化资料，逐步分析：

- **数据结构**：记录、字段、类别、数值、时间、层级、流向、空间位置及它们之间的关系。
- **统计逻辑**：统计单位、聚合方式、计数、求和、比例、排名、分布、区间及其他必要计算。
- **图形机制**：图形由哪些几何元素构成，数据如何转化为位置、长度、面积、角度、颜色、形状、连线或重复符号。
- **变量映射**：每个数据字段对应哪个视觉通道，是否存在分组、嵌套、排序或多变量映射。
- **适用条件**：图形需要什么样的数据，适合回答什么问题，以及可能产生的误读和表达限制。
- **案例应用**：识别信息图形案例实际使用的统计图形，说明其数据前提、计算逻辑和视觉作用。

## 与其他目录的关系

- 01-信息图形数据逻辑：研究信息图形类型的数据组织逻辑。
- 02-信息图形类型案例：保存具体信息图形类型的案例研究。
- 03-统计图形分析：研究案例中采用的统计图形及其数据—计算—视觉转换机制。

一个信息图形类型可以组合多个统计图形；同一种统计图形也可以服务于不同的信息图形类型。因此，统计图形分析不与信息图形类型一一对应。

## 当前状态

本目录目前仅建立研究框架。RAWGraphs 仓库已作为后续研究参考来源进行读取；尚未在本目录写入具体统计图形分析结论。后续分析应以可核查的源码、图形配置、数据样例和文档为依据，并区分源码事实与研究者解释。
