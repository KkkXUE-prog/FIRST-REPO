# 地标型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以具有辨识度的地理实体/建筑/自然标志作为空间锚点，建立地标实体、位置、名称、属性和周边关系。

## B. 统计图形：统计方式与计算方式

地标地图、注记地图、导览图、地标路线图、地标分布点图；可计算距离、可达性、密度、路线长度及邻近关系。

## C. 视觉编码：点、线、面、体、符号与色彩

点/图标表示地标；线表示路线或视线；面表示地标范围/街区；体表示建筑体量或高度；符号需易辨识；色彩区分地标类别、路线或重要程度。

## D. 数据／信息架构

字段包括 landmark_id、名称、经纬度、类别、年代、功能、照片、来源、周边关系；处理同名地标、坐标精度、历史名称与地标边界。

## E. 视觉叙事架构

先建立区域方位，再以主要地标定位，按路线、主题或重要性串联，最后形成空间记忆或游览路径；需兼顾地图方向与文字注记。
