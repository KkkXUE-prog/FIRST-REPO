# 手稿型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以手写文献、草图、原始笔记或手绘图作为核心资料；数据结构包括文献实体、页/片段、转录文本、图像区域及释读信息。

## B. 统计图形：统计方式与计算方式

手稿影像对照、文本转录、时间/版本比较、注释图；可统计词频、符号频次、修订次数或版本差异，但需先完成可靠转录。

## C. 视觉编码：点、线、面、体、符号与色彩

原稿笔迹与纸面是主要视觉证据；点框选局部；线连接注释与原文；面标出段落/图块；色彩区分原文、释读和后期标注，不能覆盖原始痕迹。

## D. 数据／信息架构

字段包括 manuscript_id、folio/page、image_region、transcription、author、date、material、annotation、confidence、provenance；区分原文、现代转录和研究者推断。

## E. 视觉叙事架构

先展示原件和出处，再引导读者观察局部笔迹/图形，随后给出转录与语境解释，最后说明其历史或知识意义及释读不确定性。
