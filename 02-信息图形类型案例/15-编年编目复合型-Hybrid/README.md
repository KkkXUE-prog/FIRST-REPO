# 编年与编目混合型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

同时按时间排列记录并按类别/主题编目；数据结构是带日期和分类标签的事件/条目表，可按时间或类别两个维度检索。

## B. 统计图形：统计方式与计算方式

时间轴+分类泳道、分组时间线、日历热力图、时间×类别矩阵；可计算各类事件频数、阶段分布、类别占比和时间间隔。

## C. 视觉编码：点、线、面、体、符号与色彩

点表示具体事件；线表示时间顺序；面/泳道表示类别或时期；符号区分条目类型；色彩编码分类，时间位置编码先后，避免两者混淆。

## D. 数据／信息架构

字段包括 record_id、date、category、subcategory、title、description、source；采用时间字段与分类字段双索引，处理多标签、跨期事件及不确定日期。

## E. 视觉叙事架构

先按时间建立全局脉络，再通过类别分组比较同一时期不同主题，或追踪某一类别跨时期变化，最后综合时间与类别两条阅读路径。
