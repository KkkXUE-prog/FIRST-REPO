## 分类使用说明
以上目录是表现形式/市场应用标签，不是与五种基础信息组织逻辑并列的第二套互斥类型学。每个案例仍需先确定01中的唯一基础逻辑主归属，再选择一个或多个适用表现标签。新增目录目前只建立标签说明与案例入口，不代表已收录真实案例图片。

## 案例规范
新增标签目录沿用参考仓库的结构：每个标签包含 `00-标签说明.md` 与 `案例/README.md`。真实案例经来源、数据和版权核验后，再建立独立 CASE 目录。不得将空目录或模板描述成已完成案例。
