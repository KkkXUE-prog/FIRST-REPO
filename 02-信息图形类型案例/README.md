# 02｜信息图形类型案例

本目录保存案例类型说明、逐例分析与跨案例归纳。案例图片由用户提供，按后续约定单独存放；说明文档记录图片文件名/编号与分析，不把图片嵌入或复制到“01-信息图形数据逻辑”目录。

## 案例类型

1. [混合型信息图形（Mixed Charts）](01-混合型信息图形案例.md)
2. [文字型/列表型信息图形（Informational / List Infographics）](02-文字型列表型信息图形案例.md)
3. [时间轴型信息图形（Timeline Infographics）](03-时间轴型信息图形案例.md)

## 案例分析与更新约定

- 每张新案例图先建立独立案例编号，再补充案例记录。
- 分析应区分可观察事实、合理解释与尚待验证的推断。
- 新案例出现后，先更新对应案例文档的逐例记录，再更新跨案例共性、差异、原则、方法与适用条件。
- 若新证据推翻旧归纳，应在更新日志中说明调整原因，不静默覆盖。
- “01-信息图形数据逻辑”只保留抽象的数据结构/组织逻辑总结，通过相对链接引用本目录，不保存图片案例。
