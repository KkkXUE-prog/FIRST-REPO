# 文字/列表型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以文字条目为基本记录单位，通过顺序、分组或层次组织信息；数据结构通常是有序列表或带类别的条目集合。

## B. 统计图形：统计方式与计算方式

有序/无序列表、排名表、文字矩阵、词频条形图、标签云；可统计条目数、词频、排序名次及类别频数，标签云面积仅在词频映射明确时使用。

## C. 视觉编码：点、线、面、体、符号与色彩

文字本身是主要符号；点/项目符号标记条目；线分组或分隔；面形成卡片/栏；色彩强调类别、关键词或状态，字号映射重要性需有规则。

## D. 数据／信息架构

字段包括条目ID、文本、顺序号、类别、标签、优先级、来源；区分原文与规范化文本，处理重复、分词、排序依据及文本长度。

## E. 视觉叙事架构

用标题说明主题，按逻辑顺序呈现条目，借助分组和强调建立阅读节奏，结尾归纳重点；排序依据必须透明。
