# 数据字典｜CASE-0002

| 字段 | 类型 | 含义 | 说明 |
|---|---|---|---|
| record_id | integer | 本地模块编号 | 本地生成 |
| module | string | 简历模块 | 图面可见 |
| visible_content | string | 可读内容或概括 | 不可读细节不补写 |
| information_role | string | 信息作用 | 研究者归纳 |
| evidence_status | category | 证据状态 | 区分可读、部分可读与来源说明 |

**粒度：** 一行一个简历模块。并非完整履历记录。
