# 单一图表｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以一个主要图表作为信息核心，围绕一个清晰问题组织最少必要字段；数据结构由所选图表类型决定。

## B. 统计图形：统计方式与计算方式

柱图、折线图、散点图、直方图、箱线图等；分别对应比较、趋势、相关、分布和离散程度；统计方法必须匹配变量类型及研究问题。

## C. 视觉编码：点、线、面、体、符号与色彩

点、线、面或面积依图表语义映射；坐标轴表达变量和尺度；符号/颜色用于区分组别；避免不必要的3D、截断轴和双轴误导。

## D. 数据／信息架构

明确分析单位、变量、维度、度量、单位、样本范围和来源；说明宽表/长表转换、聚合函数、筛选条件和缺失值处理。

## E. 视觉叙事架构

标题提出问题，主图提供证据，注释标出关键模式，结尾给出谨慎结论；一张图聚焦一个主要信息，不堆叠无关叙事。
