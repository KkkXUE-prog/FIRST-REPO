# 数据字典｜CASE-0001

| 字段 | 类型 | 含义 | 来源／清洗 |
|---|---|---|---|
| record_id | integer | 本地样本行号，不是官方街区 ID | 本地生成 |
| neighborhood_name | string | 图面可辨认的街区名称 | 人工转录，保留英文 |
| city | string | 城市归属 | 作品标题与地图语境 |
| record_status | category | 证据状态 | 标记为 published image 可见样本 |

**粒度：** 一行一个图面可辨认的街区名称。此 CSV 不是完整 GIS 数据，也不含真实边界坐标。
