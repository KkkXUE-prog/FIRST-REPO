# 层级型信息图表｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以层级结构为数据骨架，同时把数量、占比或其他指标编码到层级节点；区别于纯层级型之处在于节点通常还承载可比较数值。

## B. 统计图形：统计方式与计算方式

矩形树图、旭日图、圆形树图、树状图；可计算父级汇总、子项占比、层级贡献和分支规模，要求数值可按层级合理汇总。

## C. 视觉编码：点、线、面、体、符号与色彩

节点位置/嵌套表示层级；矩形面积或弧段角度表示数量；颜色表示类别或第二指标；边界线区分层级；面积必须对应数值，不能仅作装饰。

## D. 数据／信息架构

树结构字段 node_id、parent_id、level、label、value、category；检查父子值是否可加总、重复计入、缺失父节点及不同层级粒度。

## E. 视觉叙事架构

先呈现整体总量，再逐层下钻到子类，比较各分支贡献，最后定位主要组成；需提供层级路径和面积/颜色图例。
