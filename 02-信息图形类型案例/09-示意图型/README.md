# 示意图型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以简化结构、部件及其关系解释对象如何构成或运作；数据本质是部件清单、连接关系和空间/功能约束。

## B. 统计图形：统计方式与计算方式

结构示意图、剖面图、爆炸图、原理图、网络关系图；可统计部件数量、连接度、路径长度，但主要目的通常是解释而非统计推断。

## C. 视觉编码：点、线、面、体、符号与色彩

点表示接口/节点；线表示连接、力或流向；面表示部件/区域；体表示三维结构；符号采用行业约定；色彩区分部件、功能或介质，箭头表示方向。

## D. 数据／信息架构

包含实体/部件表、关系表、位置/坐标、功能、材料、方向及注释；区分真实比例图与非比例示意，标注省略、剖切和符号图例。

## E. 视觉叙事架构

先展示整体对象，再分解局部部件，沿连接/作用方向解释机制，最后回到整体理解系统；阅读路径需避免交叉线歧义。
