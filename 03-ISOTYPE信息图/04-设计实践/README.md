# 04｜ISOTYPE设计实践

本目录用于记录从主题与数据到图符系统和信息图作品的实际设计过程。

## 建议工作流程
1. 确定主题、目标读者、媒介与传播任务。
2. 核验来源，建立基础数据集、数据字典和缺失值说明。
3. 判断作品的基础信息组织逻辑，并选择适当表现形式。
4. 建立图符语义字典，确定形状、比例、风格、排列和数量单位。
5. 建立数据字段到视觉变量的映射表，校验图例、单位、文字和来源。
6. 检查图符一致性、信息层级、可读性和误读风险。
7. 保存源数据、设计过程、实验记录、成品与版权凭据。

## 项目记录
真实项目可按 PROJECT-0001-主题名称 建档，记录基础数据集、数据字典、图符规范、设计分析与成品。没有实际开展的步骤不得标注为已完成；仅借鉴视觉风格的作品须明确标记 ISOTYPE-inspired。
