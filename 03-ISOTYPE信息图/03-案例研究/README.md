# 03｜ISOTYPE专项案例研究

本目录保存可核验的 ISOTYPE 方法与视觉语言案例，属于独立专项研究，不是第十八种信息图形类型。

## 案例类型
1. **历史原作：** 可核实属于维也纳图像统计法或 ISOTYPE 体系的作品，注明作者、年代、馆藏/出版来源和版权状态。
2. **当代方法应用：** 能够证明使用图符词汇、标准化数量单位或系统性信息转译方法的作品。
3. **视觉借鉴案例：** 仅借鉴扁平象形符号或版式风格的作品，标记为 ISOTYPE-inspired，不冒称历史原作或完整方法应用。

## 建议归档结构
```text
03-案例研究/
├── README.md
└── CASE-0001-作品名称/
    ├── 分析.md
    ├── 基础数据集.csv
    ├── 数据字典.md
    └── 原图来源.md
```

只有在真实案例得到核验后才建立 CASE，不预置虚构案例。无公开再发布权限时保留官方来源链接和版权状态，不擅自复制图片。
