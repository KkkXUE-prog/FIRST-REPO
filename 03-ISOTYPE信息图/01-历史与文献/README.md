# 01｜ISOTYPE历史与文献

本目录用于核验 ISOTYPE 与维也纳图像统计法的发展史、代表人物、出版物、历史作品和档案出处。

## 核心研究线索
- Otto Neurath 与维也纳图像统计法的发展背景。
- Marie Reidemeister（Marie Neurath）参与的资料—图像转译工作。
- Gerd Arntz 的图符系统与视觉语言。
- ISOTYPE 名称的形成、历史传播、代表项目与后续影响。

## 资料记录规范
每条资料尽可能记录作者、题目、年份、出版或馆藏机构、URL/出版信息、页码、内容摘要、可靠性及使用权。历史图片若无公开再发布许可，仅保留经验证的来源链接与权利状态，不冒充已归档原图。

本目录先核验资料，再形成历史叙事；不得为了填满时间线而推测或编造年份。
