# 02｜ISOTYPE图符语言与视觉编码

## 研究目标
分析 ISOTYPE 的图形词汇、语义映射、数量表达、版式和信息转译方法，避免将 ISOTYPE 简化为一种扁平图标风格。

## 关键研究维度
1. **图符词汇：** 同类对象的轮廓、比例、视角和抽象层级是否统一；是否存在图符 ID 与语义字典。
2. **数量语法：** 若使用重复图符表达数量，是否保持单个图符尺寸一致；是否注明一个图符代表的数量单位、取整及部分符号规则。
3. **空间与排版：** 基线、行列、间距、对齐、方向、分区、标题和图例如何支持阅读。
4. **色彩与文字：** 色彩是否稳定映射类别或重点；单位、来源和必要语境是否得到保留。
5. **信息转译：** 原始资料如何经过筛选、语义提炼、图符设计和可读性检验，转化为视觉信息。

## 数据组织
可使用原子字段记录 item_id、category_id、value、unit、symbol_id、source_id。多标签或一对多关系应采用关联表。无数量字段时可以研究图符语言，但不能宣称其为定量统计图。
