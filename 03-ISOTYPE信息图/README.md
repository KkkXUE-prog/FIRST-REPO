# 03｜ISOTYPE信息图专项研究

> 独立研究项目。ISOTYPE 是一种以标准化图符和信息转译为核心的视觉教育与信息设计体系，不是第六种基础信息组织逻辑，也不是 02 中的一种信息图形表现标签。

## 项目研究对象
ISOTYPE（International System of Typographic Picture Education，国际图像文字教育系统）及其历史前身维也纳图像统计法。研究图符语言、信息转译、数量表达、视觉编码、历史文献、真实案例与设计实践。

## 与仓库其他部分的关系
- [01-信息图形数据逻辑](../01-信息图形数据逻辑/)：每件作品仍按五种基础逻辑确定主归属。
- [02-信息图形类型案例](../02-信息图形类型案例/)：记录作品的表现形式；ISOTYPE 不再作为其子标签。
- [04-统计图形分析](../04-统计图形分析/)：研究统计图形与数据结构。ISOTYPE 可使用象形符号表达统计数据，但不等同于某一种统计图。
  
## 研究边界
区分历史 ISOTYPE 原作、可核实采用其方法的当代作品，以及仅借鉴其视觉风格的作品。数量图符必须注明单位和换算规则；没有来源证据的历史事实、案例或统计数值不得补造。
