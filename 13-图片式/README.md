# 图片式｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以照片、插画或图像单元承载主要信息，数据记录常由图像资产及其标签、元数据、注释和关联关系构成。

## B. 统计图形：统计方式与计算方式

图像矩阵、图像时间序列、图片墙、注释图、图像分类图；若有可量化标签可做频数/分类统计，但不能仅凭视觉印象推断数值。

## C. 视觉编码：点、线、面、体、符号与色彩

图像本身是主要符号；点标注局部；线引导视线/标注；面形成图像版面；体可表达空间对象；色彩需考虑原图色彩与叠加标记对比度。

## D. 数据／信息架构

资产表包括 image_id、文件/URL、作者、许可、时间、地点、类别、说明、来源；建立缩略图与原图关联，记录版权、替代文本和图像版本。

## E. 视觉叙事架构

通过图像序列、并置、放大细节和注释建立观看顺序；说明图片之间的比较关系及证据出处，避免图片仅作装饰。
