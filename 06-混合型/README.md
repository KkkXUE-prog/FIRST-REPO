# 混合型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

将两种或以上数据逻辑组合，例如时间+地理、层级+数量、分类+流向；核心是多个字段系统在同一作品中协同而非单一图表叠加。

## B. 统计图形：统计方式与计算方式

组合地图、时间序列+地图、桑基/冲积图、分面小多图、网络叠加；统计方法取决于各字段，须分别说明量纲、汇总口径和连接键。

## C. 视觉编码：点、线、面、体、符号与色彩

点线面体分别承担位置、路径、区域和量值；符号编码对象类别；色彩可区分维度但控制编码数量；同一视觉变量不要同时表达冲突含义。

## D. 数据／信息架构

建立主实体表及时间、空间、类别、关系等子表；明确主键、外键、粒度、连接方式、单位与缺失值；避免不同粒度数据直接相乘或错误连接。

## E. 视觉叙事架构

先确立主线，再引入辅助维度解释主线，最后综合多维关系；需提供图例、阅读顺序和维度切换提示，避免视觉过载。
