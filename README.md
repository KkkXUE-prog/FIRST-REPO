# 信息图形研究与案例分析

本仓库用于建立信息图形的数据逻辑分类体系，并通过用户提供的案例图持续归纳类型特征、视觉编码、信息架构与视觉叙事方法。

## 目录结构

- [01-信息图形数据逻辑](01-信息图形数据逻辑/)：五类信息图形的数据逻辑定义。只保存文本总结，通过相对链接连接案例文档，不保存图片案例。
- [02-信息图形类型案例](02-信息图形类型案例/)：混合型、文字型/列表型、时间轴型信息图形的逐例分析与跨案例归纳。

## 工作方式

1. 用户提供案例图。
2. 在“02-信息图形类型案例”对应文档中记录单例分析。
3. 对照案例证据更新“01-信息图形数据逻辑”中的抽象定义。
4. 同步维护版本与更新日志，明确哪些结论已由案例支持、哪些仍待验证。

> 当前文档为分析框架初稿，尚未基于案例图完成实证归纳。
