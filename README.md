## 维护原则
- 01 保存基础类型定义；案例图片、来源和逐图分析统一保存在 02，通过链接互相引用。
- 02 的分类目前保留现状，待进一步比较研究后再决定是否调整。
- 03 独立研究 ISOTYPE 方法体系，不将其计入信息图形类型数量。
- 04 研究统计图形本身，为案例分析提供数据与计算层面的依据。
- 区分原图直接提供的数据与研究者抽样转录的数据；不虚构缺失数值、来源或版权信息。
