## 维护原则

- 第一部分只维护类型理论定义，不重复保存案例图片或案例全文；通过 Markdown 链接连接第二部分。
- 第二部分保存真实案例、来源、数据摘录、清洗过程、统计图形、视觉编码与叙事分析。
- 第三部分聚焦统计图形本身及其数据逻辑，为第二部分案例分析提供统计图形层面的研究依据。
- 区分原图直接提供的数据与研究者从图中抽样转录的数据。
- 不虚构缺失数值、统计方法、授权信息或案例事实。
- 新增案例后，回看对应类型定义和设计原则，依据证据更新文档。
