# 时间轴型｜类型定义与基础设计逻辑

> 本文档定义该类型的信息组织本质、图形统计逻辑、视觉编码、信息架构与叙事方式。具体案例是否符合该类型，需回到原图、来源和实际数据逐项验证；不能把类型定义当作案例事实。

## A. 基本的数据逻辑：数据结构的本质

以一条或多条时间尺度作为空间骨架，记录事件在时间上的位置、持续区间和重叠关系；强调时间刻度与持续时间。

## B. 统计图形：统计方式与计算方式

线性/螺旋时间轴、甘特图、事件带、时间热力图；可计算持续时长、事件间隔、重叠率、频次及阶段密度。

## C. 视觉编码：点、线、面、体、符号与色彩

点表示时点事件；线表示时间轴或持续区间；面表示阶段带/时间窗口；体积少用，除非第三变量明确；符号区分事件类型；色彩区分轨道、时期或状态。

## D. 数据／信息架构

字段包括 start_time、end_time、event、duration、category、lane、source；统一时区和日期精度，处理区间跨越、重叠、未知时间及不同时间尺度。

## E. 视觉叙事架构

沿时间轴从过去到未来或按指定方向阅读，关注并行事件、持续、间断和关键节点；必须清楚标注时间方向和刻度比例。
